How it works

10 GB on disk. 72 MB in memory.

Most editors read the whole file into RAM before they show you a single line. Hefty never does. It maps the file and only touches the part you are looking at.

  1. Map, don't loadThe file is memory-mapped, so opening is instant whatever the size. macOS pages in only the bytes on screen.
  2. Index in the backgroundA line index builds while you work. You can scroll, jump to 50% or search before it finishes.
  3. Edit without copyingA piece table records your changes next to the original, so typing stays fast however big the file is.

A real editor, not a viewer

Everything you expect from a Mac editor.

Find & replace ⌘F

Regex, whole word, match case, live match counts, Find All and Replace All.

Undo that survives save ⌘Z

Unlimited undo and redo, kept even after you save. History stores only what changed.

Go anywhere ⌘L

Jump to a line, line:col, a percentage like 50%, or a byte offset.

Syntax coloring

SQL, JSON, XML, CSV and more, picked by file extension.

Multi-cursor

Edit many lines at once, plus line commands and auto-indent.

Word wrap ⌥⌘W

Wrap long lines on or off. Arrows and scrolling move by visual row.

Crash recovery

Unsaved edits are journaled every few seconds and offered back after a crash.

Encodings & line endings

25 encodings including UTF-16 and Latin-1, with LF, CRLF and classic CR files.

Themes & tabs

System, Light, Dark and Solarized themes, zoom, tabs and Open Recent.

Install

Get Hefty.

Hefty is free and open source. Grab the latest build from GitHub Releases, or build it yourself with Swift.

Download the app

  1. Download the DMGFrom the latest release on GitHub.
  2. Drag Hefty to ApplicationsOpen the DMG and drop the kettlebell on the Applications folder.
  3. Allow it the first timeHefty isn't notarized yet, so macOS asks once. Open it, then go to System Settings › Privacy & Security and click Open Anyway.
Download for Mac

Build from source

Needs macOS 13 or later and the Xcode command line tools.

$ git clone https://github.com/NikhilPanwar/Hefty.git
$ cd Hefty
$ swift build -c release
$ swift test      # engine tests

Read the code, file an issue, or send a pull request. Every line is on GitHub.

Questions

Opening large files on a Mac.

How do I open a large text file on a Mac?

Download Hefty, then drag the file onto its icon or use File › Open. Hefty memory-maps the file instead of reading it all into RAM, so a 10 GB file opens in under three seconds and stays responsive while you scroll, search and edit.

What is the best app to open a 10 GB, 50 GB or 100 GB file on Mac?

Hefty is built for exactly that. It opens multi-GB text files of any size your disk can hold, because memory use follows what's on screen rather than the size of the file. With a 10 GB SQL dump open it used about 72 MB of RAM.

How do I view a huge log file on macOS?

Open the .log file in Hefty. You get colored, searchable text with regex find, and if the log is still being written Hefty follows new lines at the bottom, like tail -f with a full editor attached.

How can I open a large CSV file on Mac without Excel?

Excel and Numbers stop at around a million rows. Hefty opens CSV and TSV files with hundreds of millions of rows as text, colors the header and quoted fields, and lists every matching row with Find All.

Can I edit a large SQL dump on Mac?

Yes. Find the row, change it and save. Hefty keeps your edits in a piece table, saves safely, keeps the file's permissions, and lets you undo even after saving. It works with mysqldump and pg_dump output.

Is there an EmEditor or UltraEdit alternative for Mac?

Hefty is a free, open-source alternative for Mac users who need what EmEditor or UltraEdit do on Windows: open giant files quickly, search them fast, and edit them in place. It is a native Swift and AppKit app, not a web wrapper.

How do I open a big JSON file on Mac?

Open it in Hefty for syntax coloring and fast search. If the JSON is minified onto one line, use Pretty-print JSON to write a readable, indented copy.

Is Hefty free?

Yes. Hefty is free and open source. The code and every release are on GitHub.

Hefty brand sheet

Hefty is a native Mac editor for huge text files. The mark is a kettlebell whose face is a page of text: heavy files, handled with ease. Tone is confident, plain and a little playful.

Name and tagline

Hefty. Always one word, capital H. "Hefty for Mac" when the platform matters.

Tagline: The text editor for files too big for everything else. Headline: Open the file nothing else can.

Logo

Hefty

Wordmark: SF Pro Rounded Heavy in the app and DMG, Inter Black on the web. Keep clear space equal to the handle's thickness around the mark. Don't recolor the kettlebell, add outlines, or set the wordmark in a light weight.

App icon

Generated from scripts/make-icon.swift on the macOS grid (824 pt tile in a 1024 canvas). Small sizes drop the text lines so the shape stays crisp. Hefty.icns holds all ten sizes.
